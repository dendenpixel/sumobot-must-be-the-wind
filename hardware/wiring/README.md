# Wiring

The wiring is written up at block level in [`docs/hardware/WIRING_OVERVIEW.md`](../../docs/hardware/WIRING_OVERVIEW.md), with the pin groups in [`docs/PIN_MAP.md`](../../docs/PIN_MAP.md). The wire-by-wire build guides aren't published.

There's no PCB, the build is hand-wired protoboard (Board B on the base roof & Board L in the lid).
